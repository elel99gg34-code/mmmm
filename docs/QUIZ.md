# 퀴즈 문제 추가하기

퀴즈 배틀의 문제는 [`shared/data/quiz-bank.js`](../shared/data/quiz-bank.js)에
들어 있습니다. 평범한 자바스크립트 배열이라 편집기만 있으면 됩니다.

## 형식

```js
{
  q: '대한민국의 수도는?',            // 질문
  a: ['서울', '부산', '인천', '대전'], // 보기 4개 (반드시 4개)
  c: 0,                              // 정답 보기의 인덱스 (0~3)
  cat: '상식',                        // 카테고리
  d: 1,                              // 난이도 1(쉬움) ~ 3(어려움)
}
```

**정답을 항상 0번에 두어도 됩니다.** 경기가 시작될 때 보기 순서를 시드 기반으로
섞기 때문에, 어느 자리에 적어 두었는지는 화면에 드러나지 않습니다. 그래서 은행
파일에서는 읽기 쉽게 정답을 맨 앞에 적는 편이 낫습니다.

## 카테고리

`CATEGORIES` 배열에 정의되어 있습니다.

`상식` · `과학` · `역사` · `지리` · `문화예술` · `스포츠` · `IT` · `수학` · `언어`

새 카테고리를 만들려면 `CATEGORIES`에 문자열을 추가하세요. 방 설정의 카테고리
선택지에 자동으로 나타납니다.

## 난이도

| 값 | 뜻 | 봇에 미치는 영향 |
|---|---|---|
| `1` | 대부분 아는 상식 | 봇이 잘 맞힙니다 |
| `2` | 학교에서 배운 정도 | 보통 |
| `3` | 알면 뿌듯한 수준 | 봇이 자주 틀립니다 |

난이도는 방 설정의 "최대 난이도"로 걸러집니다. `maxDifficulty: 2`로 두면 3짜리
문제는 출제되지 않습니다.

## 좋은 문제를 쓰는 요령

- **오답도 그럴듯하게.** `['서울', '부산', '인천', '대전']`은 좋고,
  `['서울', '바나나', '7', '파랑']`은 나쁩니다. 후자는 읽지 않고도 맞힙니다.
- **길이를 비슷하게.** 정답만 유독 길면 그것이 힌트가 됩니다.
- **논쟁의 여지가 없는 사실로.** "세계에서 가장 긴 강"처럼 자료마다 다른 것은
  질문에 기준을 명시하거나 피하세요.
- **시간이 지나도 변하지 않는 것으로.** "현재 대통령은?" 같은 문제는 금방 틀린
  문제가 됩니다. 연도를 못박으면 안전합니다.
- **한 문장으로.** 문제는 15초 안에 읽고 답해야 합니다.

## 확인하기

문제를 추가한 뒤에는 테스트를 돌려 보세요.

```bash
npm test
```

`quiz` 스위트가 문제 은행이 형식을 지키는지, 같은 시드가 같은 문제 세트를
만드는지, 보기 섞기가 정답 인덱스를 제대로 따라가는지 확인합니다.

빠르게 눈으로 보려면:

```bash
npm start
# http://localhost:8080/#/game/quiz — 컴퓨터와 한 판 돌려 보기
```

## 점수 계산

바꾸고 싶다면 [`shared/games/quiz.js`](../shared/games/quiz.js) 위쪽의 상수를
고치면 됩니다.

```js
export const BASE_POINTS = 100;        // 정답 기본 점수
export const MAX_SPEED_BONUS = 100;    // 남은 시간에 비례한 최대 보너스
export const STREAK_BONUS = 25;        // 연속 정답 1회당
export const MAX_STREAK_STEPS = 3;     // 연속 보너스 상한 (25 × 3 = 75점)
```

기본값에서는 한 문제의 최대 점수가 **275점**(즉답 + 연속 정답 유지)입니다.
느려도 정확한 사람이 빠르지만 틀리는 사람에게 지지 않도록,
정답 기본 점수를 스피드 보너스와 같게 잡아 두었습니다.

## 문제를 통째로 갈아 끼우기

다른 주제로 허브를 운영하고 싶다면 `QUESTIONS` 배열만 통째로 바꾸면 됩니다.
엔진은 배열의 형식만 알 뿐 내용은 상관하지 않습니다. 사내 교육용, 학급 퀴즈,
동아리 신입 환영회 같은 데에 그대로 쓸 수 있습니다.
